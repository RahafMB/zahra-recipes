# Recipes QR page

Static page: a lone flower fades away and opens to the recipe poster. No build step.

Files: `index.html`, `assets/flower.png` (unchanged copy of the flower artwork), `assets/recipes.png` (unchanged copy of the recipes poster).

## Host on GitHub Pages
1. Create a GitHub repository (for example `zahra-recipes`).
2. Upload everything in this folder (`index.html` and the `assets` folder) to the repository root.
3. Repository Settings, then Pages. Under "Build and deployment" choose "Deploy from a branch", branch `main`, folder `/ (root)`, and Save.
4. Wait a minute or two. The link will look like `https://<your-username>.github.io/<repository-name>/`.
5. Open the link on a phone, then make the QR code from that exact link.
